# Agendador de Tarefas

Aplicação web desenvolvida para organizar tarefas pessoais, permitindo cadastrar atividades, acompanhar seu andamento e visualizar compromissos de maneira simples e intuitiva.

O projeto foi desenvolvido com foco na prática de desenvolvimento web, manipulação do DOM, validação de formulários e armazenamento de dados no navegador.

## Funcionalidades

- **Cadastro de usuários:** criação de conta com nome, e-mail, data de nascimento e senha.
- **Login:** acesso à aplicação utilizando e-mail e senha.
- **Gerenciamento de tarefas:** cadastro, edição e exclusão de tarefas.
- **Organização:** classificação por categoria, prioridade e status.
- **Filtros:** pesquisa de tarefas por nome, data, observações, status, prioridade e categoria.
- **Perfil do usuário:** edição de informações pessoais, descrição e foto de perfil.
- **Armazenamento local:** dados salvos no navegador utilizando LocalStorage.
- **Interface responsiva:** adaptação para diferentes tamanhos de tela.

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- Bootstrap
- Bootstrap Icons
- Font Awesome
- LocalStorage

## Como executar o projeto

1. Clone este repositório:

   ```bash
   git clone https://github.com/Lazaro277/agendador-tarefas.git
   ```

2. Acesse a pasta do projeto:

   ```bash
   cd agendador-tarefas
   ```

3. Abra o arquivo `login.html` no navegador.

Não é necessário instalar dependências ou configurar um servidor para executar a versão atual.

## Armazenamento de dados

O projeto utiliza o `LocalStorage` do navegador para armazenar informações de usuários e tarefas.

Isso permite manter os dados salvos mesmo após fechar e abrir novamente o navegador. Entretanto, os dados ficam restritos ao navegador e dispositivo utilizados.

## Limitações

Este projeto é uma aplicação de estudo desenvolvida com tecnologias de front-end. Atualmente, não possui backend ou banco de dados.

A autenticação e o armazenamento são implementados exclusivamente no navegador, portanto não devem ser utilizados como solução de segurança para usuários ou informações reais.
